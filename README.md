# PolyNote
PolyNote est une application de prise de notes personnalisable. Choisissez parmi plusieurs méthodes, organisez vos pages dans des dossiers, ajoutez des images et mettez votre texte en forme. Avec ses thèmes et ses langues, PolyNote s’adapte à vos besoins pour étudier, réviser et organiser vos idées simplement.
